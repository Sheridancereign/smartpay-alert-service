# SmartPay Alert & Analytics Service

A transaction monitoring and smart analytics microservice integrated with Stripe and an LLM (Claude API). This project
demonstrates asynchronous webhook processing, idempotency, rate limiting, and periodic tasks using Django + Celery +
Redis.

## Architecture

```
Stripe Webhook → Django View (signature verification, rate limiting)
                       ↓
              PostgreSQL (transaction storage, idempotency)
                       ↓
              Celery Task Queue (Redis broker)
                       ↓
         ┌─────────────┴─────────────┐
    AI Analysis (Claude API)   Celery Beat (scheduled tasks)
    for failed payments         - metrics aggregation (every 5 min)
                                 - daily report (00:00)
```

## Tech Stack

- **Backend:** Django 6, Django REST Framework
- **Database:** PostgreSQL
- **Task Queue:** Celery, Redis (broker + cache)
- **Payments:** Stripe API + Webhooks
- **AI:** Anthropic Claude API
- **Dependency Management:** Poetry
- **Infrastructure:** Docker Compose

## Features

- Stripe webhook reception with signature verification
- Idempotent event processing (duplicate protection at the DB level)
- Asynchronous processing of failed payments via Celery
- AI-generated customer recommendations for failed payments (Claude API), with graceful fallback when the external
  service is unavailable
- Redis-based rate limiting (protection against webhook spam)
- Periodic metrics aggregation (Celery Beat, every 5 minutes)
- Daily report generation (foundation for PDF + email delivery)

## Data Model

The `Transaction` table stores:

- `stripe_event_id` — for idempotency
- `stripe_payment_intent_id`, `amount`, `currency`, `status`
- `failure_reason` — the failure reason reported by Stripe
- `ai_recommendation` — recommendation generated by Claude API
- `raw_payload` — raw JSON payload from Stripe, kept for debugging

## Running Locally

### 1. Clone and install dependencies

```bash
git clone https://github.com/Sheridancereign/smartpay-alert-service.git
cd smartpay-alert-service
poetry install
```

### 2. Environment variables

Create a `.env` file in the project root:

```env
DEBUG=True
SECRET_KEY=your-secret-key
DB_NAME=smartpay_db
DB_USER=smartpay_user
DB_PASSWORD=smartpay_pass
DB_HOST=localhost
DB_PORT=5433
REDIS_URL=redis://localhost:6379/0
STRIPE_SECRET_KEY=sk_test_...
STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
ANTHROPIC_API_KEY=sk-ant-...
```

### 3. Start the infrastructure

```bash
docker compose up -d
poetry run python manage.py migrate
```

### 4. Run the services (each in a separate terminal)

```bash
# Django
poetry run python manage.py runserver

# Stripe CLI (forwards webhooks locally)
stripe listen --forward-to localhost:8000/webhook/

# Celery worker
poetry run celery -A smartpay_project worker --loglevel=info --pool=solo

# Celery Beat (scheduled tasks)
poetry run celery -A smartpay_project beat --loglevel=info
```

### 5. Testing

```bash
stripe trigger payment_intent.succeeded
stripe trigger payment_intent.payment_failed
```

## Running Tests
